# Windows 构建与发布验收

这里列出发布门槛，**清单存在不代表已通过**。每次交付应记录实际执行的测试、产物和未验证项。

## 构建

在 `desktop` 目录执行：

```powershell
npm ci
npm run build
node src/workbench.test.mjs
npm run test:build
cargo test --manifest-path ..\rust\Cargo.toml --workspace --locked
cargo test --manifest-path src-tauri\Cargo.toml --locked
npm --prefix ..\sdk\node test
npm run tauri build -- --bundles nsis
```

`beforeBuildCommand` 使用 `npm run build:bundle`，构建前端并通过 `scripts/build-native.mjs` / `npm run build:native` 准备原生 CLI。安装目录必须同时包含桌面程序和 `pm.exe`，不能依赖 PATH 中的 Python `pm`。

准备脚本从 Cargo 的 `compiler-artifact` 消息读取实际 `pm.exe` 路径，支持自定义 `CARGO_TARGET_DIR` 和目标架构目录。构建失败、产物缺失或不唯一时直接失败，不退回旧的 `rust/target` 文件。

NSIS 产物通常位于 `src-tauri\target\release\bundle\nsis\`；设置 `CARGO_TARGET_DIR` 时以实际构建输出为准。安装器按当前用户安装，WebView2 使用 bootstrapper。完全离线部署需预装 WebView2 或使用经验证的离线安装策略。

签名证书与时间戳配置属于发布环境，不提交私钥、证书密码或认证材料。开发产物如未签名应明确标注，不宣称生产发布完成。

[CI 定义](../.github/workflows/ci.yml) 只执行自动检查与 CLI 资源准备，不构建发布安装包、不签名、不推送、不部署。YAML 校验和本机检查通过需与 GitHub 实际运行结果分别记录。

## 合成数据自动验收

所有测试使用临时 Vault 和合成秘密，禁止使用实际保险库或真实用户凭据。

| 层次        | 场景                                                                        |
| ----------- | --------------------------------------------------------------------------- |
| 核心 / 协议 | Python v2 兼容、实际 KDF 参数、中文别名和 alias_ref                         |
| 授权        | 默认拒绝、持续 / 到期范围、明确拒绝优先、撤销立即阻断                       |
| 审批        | 完整请求绑定、参数变更不可复用、并发只能消费一次                            |
| 响应        | stdout / MCP / 错误 / 审计不泄漏合成秘密；敏感字段与回显脱敏                |
| 网络        | 跨 origin 重定向阻断、Cookie 域 / 路径 / Secure 属性、写入不自动重试        |
| 生命周期    | UI 锁不暂停服务；主动暂停持久化；管理解锁不取消暂停                         |
| 客户端配置  | 合并保留其他条目，错误格式不覆盖，恢复遇到后续改动不覆盖                    |
| 迁移        | 一致性快照、原文件保留、中断保留恢复副本、导入后重新配对                    |
| 通用连接 / SDK   | state 校验、回调重放、取消、401 / 403 / 断网、固定 origin、无旧 Cookie 回退 |
| 前端        | 搜索 / 空状态、无原生接口的错误、对话框焦点 / Escape、深浅色和最小窗口      |

浏览器视觉预览使用显式 `?preview=1`，没有模拟原生操作成功。即使这些检查全部通过，仍需下面的真实设备验收。

## Windows 真实设备验收

使用独立 Windows 11 测试用户 / 测试机，在无 Python、Rust、旧 `pm` 的环境执行并记录：

1. 安装 NSIS；确认桌面与原生 CLI 均可使用。分别检查已安装 / 未安装 WebView2 的设备。
2. 创建保险库、保存密码、Token、Cookie、HTTP Basic；列表只读取元数据。人工查看失焦 / 30 秒隐藏；剪贴板 30 秒后仅在内容未变化时清除。
3. 配对 Codex / Claude，检查实际客户端工具加载和已授权请求。锁定管理界面后重复调用，确保继续成功。
4. Windows 锁屏、系统闲置、睡眠唤醒、关闭窗口分别验证；已授权调用只随系统睡眠暂停，唤醒后可恢复，管理界面保持锁定。
5. 重启并登录 Windows，服务自动恢复、管理界面仍锁定。随后主动暂停，再次重启，确认调用仍被阻断。
6. 主动暂停后仅解锁管理界面，确认没有恢复 AI 调用；再主动验证并恢复服务，确认原授权可用。
7. Windows Hello 成功、取消、不可用、验证期间锁屏及主密码回退；失败均不放开管理或服务。
8. 实际使用两个 通用连接 环境、两个账号验证绑定；登录取消、失效、403、网络中断正确区分。OAuth 不支持 state 的环境使用隔离 WebView2，不放宽校验。
9. 使用通用 Node SDK 调用已授权的只读接口，分别核对连接检查与真实请求结果。
10. 导出备份，在另一测试目录恢复；原库保留，本机恢复材料不随备份迁移，原客户端不能直接使用恢复库。

### 干净设备安装、升级与卸载

以下步骤仅由测试人员在独立 Windows 测试用户 / 测试机执行。只使用合成凭据和测试用户的可丢弃数据目录；命令行验收可用 `PM_NATIVE_HOME` 隔离。重启验收须确认手动与自动启动使用同一个测试数据目录。不得操作开发者的正常 Vault、客户端配置、登录状态或启动项。每项记录“通过 / 失败 / 未运行”和实际现象。

| 检查 | 操作与记录 | 验收点 |
| ---- | ---------- | ------ |
| 基础环境 | 记录 Windows 版本与架构；确认没有 Python、Rust、旧版 pm 和现存 pman 数据 | 安装后的桌面与原生 CLI 可独立工作 |
| WebView2 | 分别在已安装、未安装、下载失败 / 离线环境测试安装；记录取消结果 | 成功与失败状态明确；未完成安装不记录为成功 |
| 首次安装 | 核对安装包 SHA-256、签名状态与用户范围；确认安装目录中桌面程序和 pm.exe | 启动正确应用版本；CLI 契约可读取，不落入旧 Python pm |
| 权限与空状态 | 在隔离目录人工创建合成 Vault；尝试未配对 / 未授权调用 | 初始无 AI 权限；配对与授权均须人工确认 |
| 升级与降级 | 先备份合成数据，再升级；尝试较旧版本安装 | 升级后别名、账号绑定、授权与暂停状态保持；降级按当前禁止降级配置处理 |
| 卸载 | 从托盘选择退出并停止服务，再经 Windows 应用管理卸载 | 记录进程、托盘、快捷方式、启动项和客户端 MCP 配置的实际残留；失效启动或误调用残留作为发布问题 |
| 数据与重装 | 记录隔离 Vault 和配置是否保留；使用同版本重装复验 | 不默默销毁数据；保留 / 删除策略尚待维护者确认，不能仅凭卸载完成宣称数据已清理 |

卸载后的 Vault 保留策略及客户端配置清理目前没有在安装配置中明确规定。这份清单记录观察结果和待确认边界，不新增删除数据或修改授权的行为。若出现残留，只处理测试账号的合成目录并记录恢复步骤。

### Windows Hello、锁屏与重启

先用合成连接建立一个已配对、已授权的只读调用作为参照；各步骤后由测试人员检查同一调用与管理界面状态。

| 场景 | 预期与失败记录 |
| ---- | -------------- |
| Hello 成功 | 仅按本人选定动作解锁管理界面或恢复服务；单纯管理解锁不取消主动暂停 |
| Hello 取消 / 不可用 / 失败 | 管理界面或暂停服务继续保持保护状态；提供主密码回退，不自动放行 |
| Hello 验证期间锁屏 | 旧验证结果不能放开锁屏后建立的保护状态；返回后重新验证 |
| Windows 锁屏 / 系统闲置 | 管理界面锁定并隐藏元数据和秘密；已授权 AI 调用继续，未授权调用仍拒绝 |
| 关闭窗口 / 睡眠唤醒 | 关闭仅隐藏到托盘；睡眠时随系统暂停，唤醒后管理界面仍锁定，服务遵循原暂停选择 |
| 正常重启与登录 | 在测试用户允许开机启动和本机自动恢复时，管理界面保持锁定，原授权服务可恢复 |
| 主动暂停后重启 | 暂停选择持久化，AI 调用继续被阻断；只解锁管理界面仍不恢复服务 |
| 明确恢复与撤销 | 本人验证并选择恢复后才可调用；撤销对应授权后下一次调用立即被拒绝 |

Hello、锁屏、睡眠和重启必须分别记录真实设备结果。源码检查、合成渲染、单元测试或清单存在都不代表这些验收已执行。
