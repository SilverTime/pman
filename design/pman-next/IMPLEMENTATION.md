# 连接书架 · 实现说明

后续开发与验收契约见 [GLM 5.3 待办清单](GLM-5.3-TODO.md)。

## 本轮交付

- 窄侧栏、可搜索和筛选的连接书架、连接首页与账号详情；新安装默认浅色，保留已保存主题。
- 添加连接采用连续流程：选择服务 → 保存凭据或登录账号 → 选择 AI → 授权并检查。别名自动避重生成，高级字段默认收起。
- 支持 GitHub / GitLab Token 模板、通用 API / HTTP Basic、独立窗口网站登录、E10 登录及原有 OAuth 回调、个人密码保管。
- 整连接授权默认持续到撤销，支持选择多个有效客户端；高级的路径、方法、有效期与参数限制仍可使用。
- 保留凭据查看、复制、更新、收藏、账号编辑、删除、配置恢复、活动、待审批和管理锁等原有功能。
- 字体离线打包 IBM Plex Sans 与 Noto Sans SC（与思源黑体同源的中文字体）；无需页面访问外部字体服务。

## 原生接口

新增仅对已验证主窗口开放的 `grant_connection`，参数为 `site`、`clientIds`、`siteUrl`、`account`、`tenant`。

原生端在持有核心锁时核对账号上下文，验证全部客户端及其策略身份，然后在一个数据库事务中启用 AI 使用并追加连接级规则。规则覆盖代理支持的 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS 与该连接的全部路径；不设置到期时间。不修改明确拒绝、其他连接或既有规则；完全相同的规则不会重复添加。空列表、失效客户端、普通密码和锁定保险库均拒绝。

`client_test` 检查的是本机配对和代理服务，不是 AI 进程已加载配置或远端业务请求的端到端验收。界面分别显示授权保存结果与代理检查结果，检查失败不撤销已经保存的授权，也不重放业务写入。

## 当前能力边界

- GitHub / GitLab 目前使用 Token，未实现通用 OAuth 应用注册、授权交换和回调。模板不声称具备一键 OAuth。
- 网站会话可以供代理接口调用；AI 操作已登录网页的通道尚未提供，详情明确显示尚未接入。
- 已保存的 Token 不显示为身份已验证；已配对不显示为真实 AI 已连通。
- 旧策略不会自动升级成整连接授权；禁用 AI 使用的连接恢复时，界面提示既有授权也会重新生效。
- 浏览器预览仅包含合成数据；原生操作明确报错，不模拟授权、登录或保存成功。

## 验证方式

- `npm run build`：TypeScript 与生产前端打包。
- `node src/workbench.test.mjs`：界面渲染、预览隔离、状态含义、整连接规则识别与主题对比度。
- `cargo test --manifest-path rust/Cargo.toml -p pman-core`：含整连接授权原子性、幂等、撤销、拒绝规则和身份失效回归。
- `cargo test --manifest-path desktop/src-tauri/Cargo.toml`：原生身份、配置保留、生命周期、登录事务等；安装验收测试需单独提供发布二进制。
- 浏览器实测首页、详情、授权选择、预览拒绝操作、接入表单、搜索、主题及 1440×900 / 1000×700 尺寸。

本轮不包含真实账号登录验收、安装包发布或替换当前安装的软件。
