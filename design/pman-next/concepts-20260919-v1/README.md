## 提示词摘要与视觉约束

共同提示：生成 pman Windows 桌面应用的高保真正视截图；连接书架方向，暖白与炭灰、松绿色强调、适中紧凑；思源黑体与 IBM Plex Sans 的文字气质；细分隔线、分层圆角；左侧窄导航、服务账号列表、右侧主区域；准确的简体中文；合成数据；不展示凭据、原始 ID 或 HTTP 路径。

首页提示：主区显示需要重新登录的 Notion、最近使用的连接及接口和网页能力、已接入的 AI、最近活动。强调局部故障不影响其他连接。

详情提示：以首页图片为视觉参考，保持外壳一致；选中 GitHub，展示独立的接口访问和网页访问状态、持续授权的 Codex 与 Claude Code、活动记录和管理入口。

新增提示：以首页图片为视觉参考，主区呈现选择服务、登录账号、授权 AI 三步；展示账号已连接但网页尚未连接的状态；选择 Codex；整个连接授权持续至撤销；主操作为授权并检查。

## 评审边界

重点评审整体气质、信息密度、连接与账号组织、授权是否易懂。图中字体与细节为生成式视觉近似，后续原型应使用真实字体和组件精确实现。接口授权与网页登录必须独立验证，图中成功状态不代表实际能力已经交付。
